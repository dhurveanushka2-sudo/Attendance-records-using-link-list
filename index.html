Attendance Chain

Every student is a node in a singly linked list. Add, search or remove students, take roll call for a date, and read the attendance summary.

How it works

append(node):   walk to the last node, set last.next = node
remove(roll):   find the previous node, set prev.next = cur.next
find(roll):     start at head, follow next until a match or null
summary():      traverse once, count P / A / L per node
